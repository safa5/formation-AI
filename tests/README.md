# Zone QA

À produire pendant le TP, à partir de la **même spec** que le développeur :

- `cas_de_test.md` : un cas de test par critère d'acceptation (préconditions, données, étapes, résultat attendu)
- `controle_synthese.py` : script de contrôle qui calcule le résultat attendu à partir de `data/mouvements_sample.csv`, pour le comparer à la sortie du programme ADL
